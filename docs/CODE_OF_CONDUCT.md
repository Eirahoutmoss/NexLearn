# Davranış Kuralları

Bu proje, [Contributor Covenant 2.1](https://www.contributor-covenant.org/tr/version/2/1/code_of_conduct/) ilkelerini benimser.

Herkesin saygılı, kapsayıcı ve yapıcı bir ortamda katkı verebilmesini istiyoruz. Taciz, aşağılayıcı dil, kişisel saldırı ve başkalarının özel bilgilerini izinsiz paylaşmak kabul edilmez.

Kabul edilemez davranışları proje sahibine GitHub üzerinden özel olarak bildirebilirsin. Tüm bildirimler gizli tutulur ve incelenir.
